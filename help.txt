- zainstalować biblioteki `pip install -r requirements.txt --upgrade`
- Pobrać YOLOv3-608 cfg i plik weights z tej strony https://pjreddie.com/darknet/yolo/

`docker-compose.yml` odpala
- RabbitMQ
- Service A API
- Service B API
- 3 workerów

docker compose up --build

docker compose up --scale service_b_consumer=10

## Endpoints

- Service B `/detect` POST `{"url": "<image_url>", "save_img": false, "save_path": ""}` ->ID taska
- Service A `/tasks/<task_id>` GET -> status/wynik
